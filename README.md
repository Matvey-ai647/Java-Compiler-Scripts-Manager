# Компилятор Java Compiler Scripts Manager

Учебный пример на Java, который демонстрирует компиляцию исходных файлов Java средствами JDK, вывод сообщений компилятора и подключение к Oracle Database через JDBC. Компиляция выполняется локально; подключение к базе используется отдельно и само по себе не сохраняет в ней исходный код или результаты компиляции.

Давайте начнем работу!

## Возможности

- Компилировать отдельные файлы `.java` и сохранять полученные `.class`-файлы в каталоге `out`.
- Запускать скомпилированный класс через метод `compileAndRun`.
- Получать диагностические сообщения компилятора: ошибки, предупреждения и расположение проблемы в исходном файле.
- Устанавливать JDBC-соединение с Oracle Database с параметрами из файла настроек.

Компилятор подходит для обучения Java, небольших демонстрационных проектов и экспериментов с программным вызовом Java Compiler API. Это стартовый пример, а не полноценная IDE, система сборки или среда для компиляции недоверенного кода.

## Для кого

- для начинающих изучать Java и API компилятора;
- для преподавателей и студентов, которым нужен небольшой пример компиляции и диагностики;
- для разработчиков, которым требуется отправная точка для собственного инструмента с подключением к Oracle Database.
- для IT-специалистов, которые сотрудничают в крупном бизнесе для разработки корпоративных веб-систем и т.д.

Для разработки и компиляции нужен JDK (не только JRE). Для подключения к базе дополнительно нужны доступный экземпляр Oracle Database и учетная запись с необходимыми правами.

## Требования

- JDK 8 или новее;
- Maven;
- Oracle Database, если требуется проверить подключение к базе.

Проект использует Oracle JDBC-драйвер `ojdbc8` версии `19.8.0.0`. Убедитесь, что выбранная версия JDK и экземпляр Oracle Database совместимы с этим драйвером.

## Сборка и настройка

1. Склонируйте репозиторий и перейдите в каталог `java-compiler-oracle`.
2. Соберите проект:

   ```sh
   mvn clean package
   ```

3. Скопируйте `src/main/resources/application.properties.example` в `src/main/resources/application.properties`.
4. Укажите в `application.properties` адрес Oracle Database, имя пользователя и пароль:

   ```properties
   db.url=jdbc:oracle:thin:@localhost:1521:xe
   db.username=your_username
   db.password=your_password
   ```

   Замените пример URL на адрес и имя сервиса вашей базы. Не добавляйте файл с реальными учетными данными в систему контроля версий и не используйте административную учетную запись Oracle для приложения.

5. Запустите пример приложения:

   ```sh
   mvn exec:java -Dexec.mainClass="com.example.app.Main"
   ```

Приложение проверит возможность подключения к базе и выведет результат. При ошибке подключения проверьте URL, учетные данные, сетевую доступность базы и права пользователя.

## Использование компилятора

`CompilerManager` предоставляет методы для компиляции файла и компиляции с последующим запуском. Например:

```java
CompilerManager manager = new CompilerManager();
manager.compile("examples/HelloWorld.java");
```

Результат появится в каталоге `out`. Чтобы после компиляции запустить класс, можно вызвать:

```java
manager.compileAndRun("examples/HelloWorld.java");
```

Подключение к Oracle отдельно от компиляции:

```java
try (Connection connection = OracleConnectionFactory.getConnection()) {
    // Используйте соединение только для разрешенных задач приложения.
}
```

Для этого фрагмента нужны импорты `java.sql.Connection` и `com.example.database.OracleConnectionFactory`. Закрытие соединения выполняется автоматически конструкцией try-with-resources.
